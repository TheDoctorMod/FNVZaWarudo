# THE WORLD - ZA WARUDO (Time Stop)

> This **Fallout: New Vegas meme mod was made 100% with AI**.

## Requirements

- Fallout: New Vegas (version 1.4.0.525)
- [xNVSE](https://github.com/xNVSE/NVSE) 6.3.5 or newer
- JIP LN NVSE Plugin 55.10 or newer
- JohnnyGuitar NVSE 5.04 or newer
- UIO — User Interface Organizer (required for the activation visual effect)
- `TheWorldNV.dll` installed in `Data\NVSE\Plugins`

### DLL build requirements

- Visual Studio 2022 with the C++ `v143` toolset
- Windows SDK 10
- xNVSE source code
- `Win32` platform
- C++20
